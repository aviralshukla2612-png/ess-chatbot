## 1. PURPOSE & CORRECTION PRINCIPLES

Following the forensic telemetry integrity audit (`ac0bf67`), this document establishes the **corrected, trustworthy, reproducible network performance testing architecture** for Emperor Nexus.

### Mandatory Correction Invariants:
1. **Network HTTP Generation via k6:** Replaces all in-process JavaScript function calls with real HTTP/1.1 requests generated by `k6` targeting `http://127.0.0.1:3301`.
2. **Time-Based Sustained Execution:** Replaces single-pass `Promise.all` batching with sustained virtual users executing over full, time-bounded windows with realistic **1–3 second user think time**.
3. **VPS-Native Execution:** All load generators, watchdog daemons, and staging containers must execute directly on the Linux target host (`vmi3189237`, Ubuntu 24.04). Local development workstation execution is strictly prohibited.
4. **Mandatory Watchdog Start Barrier:** The load test cannot start unless a verified, live watchdog daemon is active, writing fresh atomic heartbeats (<5s old) to `/tmp/watchdog_heartbeat.json`.
5. **Preservation of Concurrency Ceilings:** In accordance with user guidance, `ConcurrencyLimiter(20, 60)` is **NOT increased**. Testing will establish actual provider latencies, queue wait times, and VPS-side behavior before considering architectural changes.

## 4. REALISTIC USER JOURNEY & WORKLOAD (8-POINT SPECIFICATION)

Every virtual user simulates a real customer visiting the widget across synthetic tenants `org_stage3_alpha_test` and `org_stage3_beta_test`:

1. **Health Verification:** `GET http://127.0.0.1:3301/api/health` -> HTTP 200.
2. **Visitor Session Initialization:** `POST http://127.0.0.1:3301/api/public/chat/${botId}/session` -> Returns `conversationId` and `visitorToken`.
3. **SSE Ticket Issuance:** `POST http://127.0.0.1:3301/api/public/chat/${botId}/ticket` -> Issues single-use 60s exchange ticket.
4. **Chat Ingestion & Stream Turn:** `POST http://127.0.0.1:3301/api/public/chat/${botId}` -> Submits message, tracks time to first token (TTFT) and full completion.
5. **Mock OTP Queue Enqueue:** `POST http://127.0.0.1:3301/api/auth/otp/send` -> Dispatches OTP verification job to Redis stream `stream:otp_dispatch`.
6. **Synthetic Lead Capture:** `POST http://127.0.0.1:3301/api/leads` -> Submits lead payload with tenant organization ID.
7. **Adversarial Cross-Tenant Security Probe:**
   - Alpha VU attempts to fetch Beta session/conversation -> Must receive 404/403.
   - Any leakage event triggers `security_cross_tenant_leaks` counter and immediate test termination.
8. **Realistic User Think Time:**
   - `sleep(1 + Math.random() * 2)` (1.0 to 3.0 seconds between user actions).
